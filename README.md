# Priority

Fabric mod that lets you set a priority order on your hotbar slots. If two hotbar keys get pressed on the same tick, the one with the higher priority wins instead of whatever Minecraft would normally pick.

Set priorities 1-9 per slot (1 checked first 9 last meaning 9 will always be selected) from the config screen (needs Mod Menu + Cloth Config) or by editing `config/hotbarpriority.json` directly. Values have to be unique or it won't let you save.
